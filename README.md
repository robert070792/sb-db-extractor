# 유승빈 DB추출기 v3.33 시험판

네이버 쇼핑 상품을 수집하고, 실제 스토어 주소와 상품번호를 검증한 뒤 회사 가망·사업자정보를 확인해 010 후보를 CSV로 저장하는 Chrome 확장 프로그램입니다.

이번 버전은 페이지 버튼을 사용자가 직접 누르면 상품 갱신을 확인하고 자동 수집하는 모드를 추가합니다. 새 작업에서 체크되어 있으며 기존 저장 작업은 원래 설정을 유지합니다. 스크롤은 약 800ms 간격, 화면 높이의 절반씩 이동합니다. 실제 네이버와 회사 서버에서의 성공 여부는 미검증입니다.

## 고정한 실행 방식

1. 키워드가 바뀌면 실제 검색창에 입력하고 돋보기 버튼을 클릭합니다. 최대 20개 키워드를 순차 처리합니다.
2. 지정한 페이지의 일반·광고·원부 관련 화면 정보를 수집합니다. 원부 추가 조회를 켰을 때 연결 판매처를 추가 수집합니다. 페이지 이동은 기본적으로 사용자가 실제 숫자 버튼을 누르며 URL을 직접 바꾸지 않습니다. 직접 누르기 옵션을 해제하면 기존 자동 클릭을 사용합니다. 목표 숫자가 없으면 같은 페이지 영역의 실제 이전·다음 버튼을 사용합니다.
3. 실제 주소 근거와 판매자·채널·상품번호를 대조합니다. 식별 충돌은 보류하며, 주소 미확인 업체도 번호 기반 조회 대상으로 보존합니다.
4. 회사 가망을 확인한 뒤 온전한 010이 있는 회사 캐시를 우선 사용합니다. 번호가 없거나 일반전화·가려진 번호이면 새로 조회합니다. 스토어 주소가 있으면 HTTPS `/store/seller-info`, 없으면 v2.9/v3.5의 판매자번호+쇼핑상품번호 `/extension/business-info`를 사용합니다.
5. 회사 서버 상태가 신규·부재·거절인 업체의 제공된 연락처 중 010을 찾고, 미확보 업체도 보류 CSV에 남깁니다. 영업 CSV는 기존 16열을 유지합니다.

## 설치·업데이트

`설치안내.txt`를 먼저 확인하세요. 기존 사용자는 기존 확장을 삭제하지 말고 **기존 확장 폴더에 새 파일을 덮어쓴 뒤 chrome://extensions에서 새로고침**하세요. 같은 Chrome 프로필·확장 ID를 유지해야 기존 조회 이력을 승계합니다.

다른 폴더에서 새 확장으로 추가하거나 Chrome 프로필을 바꾸면 이전 저장소가 자동 이전되지 않습니다. 진행 중인 작업은 중단하고 결과 CSV·전체 진단을 먼저 보관하세요. 업데이트 후 이전 결과를 보관하고 작업 초기화 뒤 새로 시작하세요. 이전 요청 이력은 보관하지만 새 작업의 필요한 조회를 차단하지 않습니다. 이어하기는 같은 작업으로 취급합니다.

## 수정 내용

`변경사항_v3.33.md`에 정리했습니다. 페이지 버튼을 화면 중앙으로 이동한 뒤 0.65초 기다리고 실제 보이는 클릭 영역·가림 없음·위치 유지 여부를 확인합니다. 화면 밖이거나 위치가 움직이면 클릭 전에 최대 두 번 더 위치를 보정합니다. 시작 화면이 3페이지여도 요청한 1페이지로 숫자 버튼을 눌러 이동합니다. 버튼이 가려지면 창을 옮기거나 접은 뒤 이어하기를 누르세요.

v3.27에서 리뷰수 필터 아래 **네이버 원부 추가 조회: 꺼짐 / 켜짐** 버튼을 추가했습니다. 최초 사용·초기화 후 기본값은 꺼짐입니다. 꺼짐에서는 화면 상품정보만 읽고 원부 판매처 API를 호출하지 않습니다. 켜짐에서는 기존 원부 판매처 조회를 사용합니다. 검색·페이지 버튼·스크롤과 회사 사업자조회는 유지됩니다.

묶음상품 제외는 최종 결과 필터이며 새 버튼과 별개입니다. 비교 중 설정이 섞이지 않도록 시작 시 설정을 이어하기에도 유지합니다. 다른 설정을 시험하려면 결과·진단을 저장하고 초기화한 뒤 새로 시작하세요. 이전 버전 작업은 당시의 켜짐을 유지하며 이전 요청 수는 미집계로 표시합니다.

진단 JSON에는 켜짐/꺼짐, 원부 추가 요청 시도·fetch 호출 확인·발신 여부 불명 횟수, 페이지별 설정 제외 원부 후보를 남깁니다. 원부 조회를 끄면 화면에 없는 연결 판매처는 확보하지 못하며, 미조회 사유를 기록합니다.

새 작업은 **페이지 버튼 직접 누르기**가 기본입니다. 원하는 범위를 설정하고 전체 자동 추출을 시작하세요. 안내된 숫자 버튼을 마우스로 누르면 프로그램이 페이지 선택과 상품 목록 갱신을 확인한 뒤 맨 위부터 자동으로 스크롤·수집합니다. 이미 시작 페이지에 있으면 바로 수집합니다. 수동 클릭 대기 중에는 화면을 자동으로 움직이지 않습니다.

직접 클릭은 최대 5분 기다립니다. 시간 초과 또는 작업 재시작 시에는 이어하기로 저장된 비교 기준을 복원합니다. 번호만 바뀌고 상품이 이전 페이지에 남아 있으면 수집하지 않습니다. 새 작업은 자동 새로고침을 하지 않으며, HTTP 418 발생 시 보존 후 대기합니다. 기존 작업은 원래 설정을 유지하므로 새 모드 시험은 결과 백업 → 작업 초기화 → 직접 누르기 체크 → 새 시작 순서로 진행하세요.

사용자가 직접 연 상품에서 실제 주소·상품번호·판매자번호가 일치하면 해당 Chrome 프로필에 연결을 기억해 이후 추출에 활용합니다. 자동 광고 클릭·새 탭 생성은 하지 않습니다. 페이지에 식별 정보가 없거나 기존 연결과 충돌하면 저장하지 않습니다. 사용자 제공 ttasomihome 주소도 반영했습니다.

일반전화·마스킹·빈 번호의 회사 캐시는 신규 조회로 넘깁니다. 신규 조회 후에도 010이 없으면 보류하며, 서버 조회 실패는 HTTP 상태·API 경로·민감정보를 제외한 오류 요약으로 구분합니다. 특이사항은 검색광고, 원부상품을 표시하며 일반상품 분류 문구는 비웁니다. 기존 사업자·전화번호 중복 경고와 16열 CSV를 유지합니다.

실제 스토어 ID가 전혀 제공되지 않는 상품의 주소는 추측하지 않습니다. `/main/products/번호`는 원본 관측값으로만 보존하고 검증된 최종 링크로 내보내지 않습니다.

## 검증과 한계

`검증결과_v3.33.md`에 실제 실행한 검사와 미검증 범위를 구분했습니다. 기존 자동 검사에는 두 키워드 × 두 페이지와 현재 3페이지에서 2~5페이지를 수집하는 DOM 기반 전체 연결 시험이 포함됩니다. 검사는 오프라인 모의 서버로 수행했습니다. 실제 네이버·회사 로그인 서버, 유료조회, 사용자 PC의 Chrome 확장 실행 성공을 보증하는 결과는 아닙니다.

부재·거절의 3일 경과 처리는 회사 서버가 반환하는 상태에 의존합니다. 회사 프로그램의 전화걸기·TM앱·통화시간·통화요약 기능을 이번 추출기 UI에 새로 통합한 것은 아닙니다. 기존 통화기록 CSV 열은 유지합니다.

사용자 제공 전체 HTML 오프라인 재현에서 일반 21·광고 12·원부 대표 19 = 52개를 식별했습니다. 실제 판매처 응답과 010 확보를 검증한 수치가 아닙니다. 관측한 상품 수, 식별하지 못한 후보 수, 업체 통합 수는 다른 지표입니다. 화면에 로드되지 않아 관측하지 못한 카드까지 정확히 셌다고 표시하지 않습니다.

## 개발·테스트

Node.js 20 이상과 Python 3을 사용합니다. 확장 프로그램 실행 자체에는 npm 의존성이 없습니다. jsdom은 개발 테스트에만 사용합니다.

```bash
npm ci
npm test
python3 tools/build_release.py
```

기존 테스트 9개 파일의 목적을 유지하고 URL 우선 이동을 기대하던 검사는 실제 숫자 버튼 클릭 요구로 갱신했습니다. 회귀검사는 `tests/test_v321_integrity.cjs`, `tests/test_v321_dom.cjs`, `tests/test_v322_workflow.cjs`, `tests/test_v323_workflow.cjs`, `tests/test_v324_workflow.cjs`, `tests/test_v325_workflow.cjs`, `tests/test_v326_workflow.cjs`, `tests/test_v327_workflow.cjs`에 있습니다. 실제 인증 쿠키나 사내 연락처 없이 모의 응답으로 검사합니다.

사용자 v3.22/v3.23 진단에서 번호 조회 HTTP 404가 확인됐습니다. 클라이언트 수정으로 서버 경로가 복구됐다고 보증할 수 없습니다. 주소를 확보한 업체는 최신 조회를 사용하며, 주소와 번호 조회가 모두 불가능한 업체는 보류합니다. 클라우드에서 문서 주소 접근 시 403 Domain forbidden을 받아 실제 조회 요청은 실행하지 않았습니다. 이는 운영 서버 자체의 장애로 확정한 결과가 아닙니다.
